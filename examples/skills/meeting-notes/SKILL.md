# Meeting notes

Use this skill when the user shares raw notes or a transcript of a meeting and wants a clean summary.

## Steps

1. Read the notes once and list the participants that are named.
2. Write a summary of three to six sentences.
3. List the decisions taken, one per line.
4. List the action items as a table with the columns: action, owner, due date.
5. If an owner or a date is missing, write "to confirm" instead of guessing.

## Output format

Markdown with the headings Summary, Decisions and Action items.
